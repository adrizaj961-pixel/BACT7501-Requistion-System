
# Purchase Requisition System

BACT7501 - Assessment 2

## Project Description
This project is a Python-based purchase requisition
system developed using object-oriented programming.

## Features
- Submit purchase requisitions
- Calculate purchase totals
- Automatically approve requests below $500
- Allow manager approval and rejection
- Display requisition details
- Generate requisition statistics
- Test functionality using unittest
# BACT7501-Requistion-System
Python purchase requisition system using object-oriented programming

## How to Run the Project

### Requirements
- Python 3
- PySide6

### Install PySide6
Open the terminal and run:

    py -m pip install PySide6

### Run the GUI
Run the following command:

    py gui.py

### Run the Console Application
Run:

    py main.py

### Run Automated Tests
Run:

    py -m unittest -v

## GUI Features
- Enter staff information
- Add purchase items and calculate totals
- Submit requisitions
- Automatically approve requests below $500
- Allow managers to approve or reject pending requests
- Display requisition records in a table
- Update requisition statistics automatically
